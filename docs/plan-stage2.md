1.5단계(현장 프리셋 · 기상청 날씨 · 내구도 원장 · 결정 카드 · 실데이터 보정) 위에 아래 요청을 얹는다.

  태풍 '지금 작업 중단 · 고정', 강풍 '감시하며 진행', 법정검사 '비번 시간 수검 예약', 정기 점검 '지금 멈추고 점검',
  중량물 '오늘 보류'. 파이프라인 판단 카드(`decision.rs`)에도 성격 표시
- `src/scoring.rs`: 핀볼 · CRPS(분위수) · 구간 점수 · PIT/KS · Brier 분해 · α–λ · 예측 지평 · 분할 등각 · 적응 등각 + 테스트

**P3 설계 메모 (R1 · R2 근거)**
- 연평균 비래염분: Sd(d) = S100 · (d/100)^−b. S100 = KICT 27개 지역 100 m 값(mdd NaCl → ×60.7 = mg Cl⁻/m²·d, 건식 거즈 →
  습식 캔들 환산 계수는 보정 대상), b = 해안별 거리 감쇠(동 0.30–0.84 · 서 0.37–0.51 · 남 0.10–0.40, 6개 지점 회귀)
- 시간 변화: 바다 쪽 방위 ±67.5° 바람 · 3 m/s 이상(ALC17) · 파고(월 1.5–2 m 면 높은 염분)로 가중하고 연평균에 맞게 정규화
- 부식: 날마다 ISO 9223 용량–반응식(검증: −33 % ~ +50 % 불확실성)을 연간 식에 정규화, ISO 9224 b(강 0.523 · 아연 0.813,
  20년 뒤 직선), 고염분은 해안 문헌 평균 0.73(ALC17) 검토. 대안식: 국내 공군기지 보정식 r = 0.3219·Sd^0.4411·exp(3.453·TOW)
- 표면 층: 노출(비 세척) · 차폐(염 누적, ISO 9223 주석) · 밀폐(기계실 · 전기실). 세척 · 도장 · 용융아연(85 µm: CX 3–10년,
  C5 10–20년) · 이중 계통 배수(해안 1.4–1.6) · 모터(IEEE 43 최소 5 MΩ · 100 MΩ, PI ≥ 2, 히터 +5–10 K) · 전장(ISA-71.04
  G1 < 300 · G2 < 1000 · G3 < 2000 Å/30일, RH 50 % 위 10 % 마다 한 단계) · 베어링 수분 (100/ppm)^0.6 (25–400 ppm)

**P6 설계 메모 (R5 근거)**
- 참 상태(숨김) = 물리 증분 × 감마 과정 잡음 × 개체 차이, 관측 = 점검 · 센서 지표(로프 단선, 라이닝 두께, 절연저항,
  진동, 차륜 지름, 도장 Ri, 클램프 시험) + 잡음 · 검출 확률. 원장 상태는 추정값으로, 고장 · 위험은 참 상태로
- 예측 판: v0 지금 방식 → v1 기존 Holt 시계열 → v2 감마 과정 베이즈 → v3 + 등각 구간 보정 · 환경 공변량
- 교차검증: 시간 순, 현장 하나 빼기(초모수), 시드 묶음. 점수: CRPS · 80 % 적중 · PIT KS · 30일 고장 확률 Brier 기술 점수

**바로 쓸 확인된 값 (R4)**
- KDS 41 12 00:2019 기본풍속(100년 · 10분 평균 · 10 m · 노출 C): 부산 38, 포항 36, 울산 34, 여수 34, 서산 34, 당진 32,
  창원 30, 인천 28, 광양 28 m/s (2022판은 500년 지도)
- 부산 HKT 안벽 크레인 14기(2013–2018): 가용률 95.0 %, 크레인당 고장 46 회/년, MTTR 0.40 h
- 국내 크레인 사망 약 31명/년(2019–2023), 크레인 46,926대(2003, 갠트리 2,551) → 사망 약 6–7×10⁻⁴ /대·년 (low)
- TT Club · ICHCA · PEMA: 운전 한계 18–19 m/s 권고, 주행 브레이크 28 m/s 유지, 레일 브레이크 35 m/s
- 태풍 매미(2003): 크레인 8기 붕괴 · 3기 탈선, 부산 순간 42.7 m/s, 계류 장력이 풍하중보다 빨리 커짐

## 1. 원칙

- 숫자마다 출처(열어 본 URL)를 단다. 찾지 못한 값은 가정이라고 쓰고 범위를 둔다.
- 새 모델은 기존 값과 맞물리게 한다: 예) 연평균 기후를 넣으면 ISO 9223 첫해 부식과 같아야 하고, 시간 단위 계산은 그 안에서 계절 · 사건 모양만 바꾼다.
- 보정은 '맞춘 항목'과 '확인만 한 항목'을 나눠 보고, 맞춘 데이터와 확인 데이터를 섞지 않는다 (교차검증).
- 저장 형식은 뒤로 호환 (`serde(default)`), 기존 프리셋 · 원장 파일이 그대로 열린다.

## 2. 구조 (층)

```
날씨 층      합성(기상청 평년값) | ERA5 재생(Open-Meteo) | API 조회 → 세계 항만 기후
   ↓
해안 염분 층  해안 거리 · 바다 방향 · 해안 형태(항내 · 개방 · 쇄파) · 높이 · 파고 · 바람 → 시간별 비래염분 Sd, 비 세척
   ↓
부식 층      젖음 시간(RH · 결로 · 염 조해 습도) + Sd + SO₂ + 기온 → ISO 9223 속도 → ISO 9224 장기(등가 시간)
             표면 미기후: 노출(비 세척) · 차폐(염 누적) · 밀폐(기계실 · 전기실)
   ↓
부품 층      도장(Ri 등급) → 강재 두께 · 피로 · 아연 · 볼트, 로프(윤활 · 아연 도금), 모터 절연저항 · 베어링,
             전장(ISA-71.04 등급), 감속기 수분, 레일 클램프 고착
   ↓
시계열 층    하루 물리 증분 × 감마 과정 잡음 × 개체 차이 → 참 상태 / 점검 · 센서 관측(잡음 · 검출 확률)
   ↓
예측 층      관측 시계열 → 남은 수명 분위수 · 기간 내 고장 확률 · 건강 점수(0–100), 구간 보정(등각 예측)
   ↓
결정 층      예측 경보 · 날씨 · 화물 · 절차 점검 → 결정 카드 (안전 · 진행 · 위험 · 중단) → 원장 · 알림
```

## 4. 점수와 측정 절차

| 점수 | 정의 | 측정 지표 | 교차검증 |
| --- | --- | --- | --- |
| 남은 수명 분포 (RUL P10 · P50 · P90) | 예측 시점에서 교체 기준까지 남은 날 | 핀볼 손실, CRPS(분위수 근사), 80% 구간 적중률, 구간 점수(Winkler), PIT 히스토그램 KS 거리, α–λ 정확도 | 시간 순 · 현장 제외 · 시드 묶음 |
| 기간 내 고장 확률 (7 · 30 · 90일) | 기간 안에 교체 기준을 넘을 확률 | Brier 점수 · 기술 점수(기후값 대비) · 신뢰도 구간표 | 같음 |
| 건강 점수 (0–100) | 남은 수명 · 불확실성을 한 숫자로 (100 신품, 0 교체 기준) | 점수 구간별 실제 고장률이 단조 감소하는지, 분포 모양 | 같음 |
| 위험 지수 | 기존 위험 모델 (20 + 40·log10 배수) | 기대 사고 대 모의 사고 수, 사고 기준율 실데이터 | 시드 묶음 |
| 부식 범주 · 속도 | ISO 9223 범주, 첫해 부식 속도 | 실측 대비 로그 오차, 범주 일치율 | 실측 지점 하나 빼기 |
| 날씨 재현 | ERA5 · 합성 날씨의 월 통계 | 월 평균 오차, 폭풍일 · 순간풍속 오차 | 기상청 지점 하나 빼기 |

## 6. 위험 · 가정

- 부식 자료는 산포가 크다 (같은 범주 안에서도 몇 배). 범주 일치와 로그 오차로 본다.
- ERA5 는 격자(약 25 km) 평균이라 해안 돌풍이 낮게 나온다 → 기상청 교차검증으로 배수를 정하고 남은 오차를 적는다.
- Open-Meteo 는 키 없이 비상업 무료(CC BY 4.0, 출처 표기). 인터넷이 없으면 저장해 둔 데이터로 동작한다.
- 국내 크레인 사고 노출 자료가 없으면 사고 기준율은 범위 가정으로 남긴다.
