# 물리 모델 · 기본값 출처 · 검증

이 문서는 샌드박스가 푸는 식, 기본값이 어디서 왔는지, 그리고 테스트로 무엇을 확인했는지를 정리한다.
**기본 크레인 제원(질량 · 모터 정격 · 감속비 등)은 예시 값**이다. 실데이터로 바꿔야 하는 값과 바꾸는 방법은
[data-sources.md](data-sources.md) 에 있다.

## 1. 본체 동역학 (`src/crane_dynamics.rs`)

하중(훅 포함)은 질점, 로프는 질량 없는 비신장 줄이다. 하중의 트롤리 걸이점 기준 상대 위치 **r**(3D)를 상태로 두고
|r| = l 구속을 로프 장력 T(라그랑주 승수)로 푼다. 각도로 매개화하지 않으므로 특이점이 없고, 권상(가변 l),
트롤리 · 갠트리 관성, 권상 회전체 관성의 결합이 그대로 들어간다.

```
T·(1/m + w_x·u_x² + w_y·u_y² + w_h) = (ṙ·ṙ − l̇²)/l + u·(g + F_e/m) − u_x·w_x·F_x − u_y·w_y·F_y + w_h·F_h
ẍ = w_x(F_x + T·u_x),  ÿ = w_y(F_y + T·u_y),  l̈ = w_h(T − F_h),  r̈ = g + F_e/m − (T/m)·u − (ẍ, ÿ, 0)
```

- w = 1/질량 (브레이크로 잠긴 축은 0), u = r/|r|, F_e = 하중 항력 + 흔들림 감쇠.
- F_x · F_y = 구동력 + 구름 · 점성 저항 + (주행) 갠트리 풍하중, F_h = 권상 구동이 감아올리는 힘.
- T < 0 이면 느슨한 로프로 보고 0 으로 자르고 횟수를 센다.
- 고전 RK4, 매 스텝 끝에 |r| = l, u·ṙ = l̇ 로 투영. 기본 dt = 2 ms.
- 편행: 갠트리를 스팬 S 강체 보로 보고, 양쪽 구동력 차(그룹 구동 토크 분담 ±1%)와 트롤리 위치에 따른
  바퀴 하중 분배가 만드는 회전을 푼다. 양 끝 어긋남이 틈을 넘으면 플랜지 안내 강성이 되돌린다.
- 바퀴–레일 점착: 환경에 점착 계수 μ 가 있으면(젖음 · 결빙, `Environment::adhesion_mu`) 주행 · 횡행의 구동력과 미끄럼
  제동력을 μ × 제동 바퀴 하중으로 자른다. 결빙 레일의 비상 정지는 더 멀리 미끄러진다 (Zhu 2011 · Takahashi 2016 의 μ).

## 2. 구동 · 모터 · 브레이크 · 로프

| 손실 | 정격 손실 P_n(1/η − 1) 을 동손 ∝ I², 철손 ∝ ψ²(ω/ω_b)^1.3, 기계손 ∝ ω² 로 분배 | `motor.rs` |
| 열 | 권선–프레임 2절점, 정지 시 자기 통풍 냉각 감소 | `motor.rs` |

## 3. 흔들림 억제 (`src/antisway.rs`, `src/motion.rs`)

- 축별 기준 속도 = 사다리꼴(가속 한계) → 상자 필터(저크 한계) → 입력 셰이퍼(ZV · ZVD · EI). 세 단계 모두 면적 1 인
  합성곱이라 이동 거리가 보존된다.
- 셰이퍼 설계 진동수 = √(g/l)/(2π). 순차 이동은 횡이동 시점의 l, 동시 이동은 평균 l 로 설계한다.
- 각도 궤환(closed_loop): 트롤리 가속도 입력 선형 진자 모델로 이산 LQR 이득을 리카티 반복으로 구한다.
  이동 중과 안정 구간 동안 각도 센서 값으로 속도 기준을 고친다.

## 6. 한계

- 하중은 질점이다 (하중 자체 회전 · 비틀림 없음). 로프 탄성 · 이중 진자는 `crane_mbd` 에서만 다룬다.
- 거더 · 다리의 탄성 변형과 흔들림의 결합은 없다. 하중 상하 진동과 거더 고유진동수의 근접만 판정한다.
- 인버터 전류 루프는 즉시 응답으로 본다. 돌풍은 재현성을 위해 결정론적 정현파 합이다.
- 로프 피로는 '권상 행정당 위험 구간이 지나는 시브 수' 로 굽힘 횟수를 센다. Feyrer 식의 항 배치는 원서로 확인해야 한다.
- 브레이크 마모는 카탈로그의 마찰일 비례 관계다. 크레인 라이닝의 실측 마모율은 찾지 못했다.
- TTM-R3 · LAYA 코드는 endmill-sandbox 에서 그대로 옮겨 빌드만 확인했고, 크레인 데이터로 학습 · 검증하지 않았다.
- 데스크톱 셸(Tauri v1)은 리눅스에서 타입 검사만 했다 (실행은 Windows 에서 확인 필요).
